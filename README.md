# Cosmological Simulation in ΛCDM Model

## Overview
This project presents a numerical and visual simulation of the expansion of the universe based on the ΛCDM cosmological model. It aims to provide an intuitive understanding of key cosmological quantities using Python.

The project is developed for educational purposes and to strengthen my background in computational physics and cosmology.

---

## Objectives
- Compute the Hubble parameter H(z) as a function of redshift  
- Analyze the evolution of the scale factor a(z)  
- Estimate the comoving distance in an expanding universe  
- Compare different cosmological models (Matter-dominated, Dark Energy-dominated, and ΛCDM)

---

## Theory
The ΛCDM model is the standard model of cosmology, where the expansion rate of the universe is given by:

H(z) = H₀ √(Ωm(1+z)³ + ΩΛ)

where:
- H₀ is the Hubble constant  
- Ωm is the matter density parameter  
- ΩΛ is the dark energy density parameter  

---

## Tools and Libraries
- Python  
- NumPy  
- Matplotlib  
- Jupyter Notebook

---

## Results
The simulation demonstrates how different cosmological parameters affect the expansion history of the universe.

- Matter-dominated models show decelerating expansion  
- Dark energy-dominated models show accelerated expansion  
- ΛCDM provides a balanced model consistent with observations
