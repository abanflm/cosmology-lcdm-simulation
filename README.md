# Cosmological Simulation (ΛCDM Model)

This project presents a numerical simulation of the expansion of the universe using the ΛCDM model.

## Features
- Hubble parameter analysis H(z)
- Scale factor evolution
- Comoving distance calculation
- Comparison of different cosmological models

## Tools
- Python (NumPy, Matplotlib)
- Jupyter Notebook

## Motivation
This project was developed as part of my preparation for graduate studies in cosmology, focusing on computational modeling and large-scale structure analysis.
